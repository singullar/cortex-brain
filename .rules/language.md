# Language Rule

## One language per vault

All content in this vault is written in **English**. To run the vault in another language, change the word above and keep the rest of this rule.

**Applies to:**
- File names (kebab-case)
- File content (body text, headings, lists, tables)
- Frontmatter fields and values
- Commit messages

**Rule:** if the agent receives input in another language, it translates and stores the output in the vault's language.

**Why:** the vault is operated by AI agents. A single language keeps parsing, linking and retrieval predictable.
