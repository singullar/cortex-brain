## Definition

A way of building software in which the problem is explored and a plan is written and checked before any code changes. The written artifacts, not the chat history, carry the work forward.

## Details

A cycle runs explore, plan, execute, review and close. Closing the cycle produces a summary that can be ingested into a knowledge vault.
