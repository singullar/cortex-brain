## Summary

Knowledge produced during software work is usually lost when a session ends. A vault gives it a place to land, with sources, concepts and entities linked through a routing index. Because new material updates existing pages, value compounds across work cycles. Spec-driven development pairs well with this, since each cycle explores first and records its findings last.

## Key Points

- Decisions and trade-offs evaporate unless written where the next session looks
- An index lets readers reach the right page without loading everything
- New sources update existing concepts instead of starting from zero
- Cycles that end by recording findings produce ready input for the vault
